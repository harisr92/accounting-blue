Ledger posting for a GST invoice

An issued invoice is one journal entry: the buyer owes the total, the taxable value is sales revenue, and each tax component is owed to the government. posting_legs turns a GstBreakdown into those legs and GstInvoice::to_entries maps them onto accounts. The legs always balance, because the breakdown’s total is its taxable value plus its tax.
