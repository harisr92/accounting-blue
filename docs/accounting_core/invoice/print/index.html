Printable view of a GST invoice

InvoicePrint is everything a printed tax invoice shows, with every amount already formatted in Indian digit grouping. It is built by the pure InvoicePrint::from_invoice from a GstInvoice and the InvoiceParties that issue and receive it, and serialises to JSON as is. The PDF renderer (behind the pdf feature) only lays this model out on the page.
