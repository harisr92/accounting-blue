accounting_core::document

Module validation 

Source
Expand description

Checks every invoice or credit note must pass, whatever its tax regime

A document’s fields are public and can be edited after it is built, and one rule depends on the date it is checked on. validate_document runs every rule and returns a ValidationReport listing each ValidationIssue found, so a caller sees all problems at once rather than the first.

Issues are Severity::Error when the document must not be issued or posted, and Severity::Warning when it is valid but worth a second look. The rule functions are public so a regime with rules of its own, such as Indian GST, can run them alongside its own.
