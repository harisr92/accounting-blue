accounting_core::reconciliation

Module types 

Source
Expand description

Core data structures for reconciliation

Two record kinds flow into the engine: LedgerTransaction (internal, projected from a double-entry Transaction onto a single account) and ExternalTransaction (a row from a bank statement, payment gateway, UPI provider or card issuer). Both keep a positive amount and carry direction in EntryType, exactly like Entry.
