Module similarity

Text normalisation and similarity scoring for transaction descriptions

Bank narrations wrap the useful part in channel codes, slashes and reference fragments ("NEFT/ACME LTD/HDFC0000123" for what the ledger calls "Acme Ltd"). Similarity therefore combines three views and takes the most generous: token overlap, edit distance, and containment.

Functions§

Levenshtein edit distance between two strings, in characters
normalize
Lowercase text, replace every run of non-alphanumeric characters with a single space, and trim.
similarity
Score how alike two descriptions are, in 0.0..=1.0.
